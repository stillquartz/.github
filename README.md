# stillquartz/.github

GitHub Organization (`@stillquartz`) のプロフィール定義リポジトリです。

- [`profile/README.md`](./profile/README.md) — Organization トップページのプロフィール表示
- [`profile/assets/`](./profile/assets/) — プロフィール表示用 SVG（ライト／ダーク自動切替）

> Note: GitHub Organization の公開トップページ（外部閲覧者向け）に `profile/README.md` を表示する場合は、このリポジトリの Visibility を **Public** に設定してください。
